# Sales Data Analysis

A simple SQL project for analyzing sales data, customers, products, orders, and revenue.

## Project Overview

This project demonstrates basic SQL skills used to organize, query, and analyze sales data.

The database includes information about:
- Customers
- Products
- Orders
- Sales revenue

## Project Files

- `schema.sql` - Creates the database tables and relationships.
- `sample_data.sql` - Contains sample customer, product, and order data.
- `queries.sql` - Contains SQL queries used for sales analysis.

## SQL Skills Demonstrated

- SELECT
- JOIN
- GROUP BY
- ORDER BY
- SUM
- COUNT
- Primary Keys
- Foreign Keys
- Aggregate Functions

## Analysis Included

The SQL queries are used to analyze:

- Total sales revenue
- Best-selling products
- Customers with the most orders
- Revenue generated by each customer

## Database Structure

The project contains three main tables:

### Customers
Stores customer information such as name, email, and city.

### Products
Stores product information such as product name, category, and price.

### Orders
Stores order information and connects customers with purchased products.

## Purpose

The purpose of this project is to demonstrate fundamental SQL database and data analysis skills through a simple sales dataset.
